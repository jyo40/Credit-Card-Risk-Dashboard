
# Credit Card Risk Dashboard

## Project Description
This project is a Credit Card Risk Dashboard that analyzes customer credit information and predicts the risk of credit card default.

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js

## Features
- Credit card default risk analysis
- Logistic Regression, Decision Tree and Random Forest models
- Interactive charts and visualizations
- High-risk customer identification
- Customer filtering based on age and credit limit
- Model performance comparison

## Dataset
UCI Credit Card Default Dataset.

## How to Run
1. Download the project files.
2. Extract the ZIP file.
3. Open index.html in a web browser.
4. Upload the CSV dataset or use demo data.
